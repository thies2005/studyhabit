# StudyHabit 1.0.1 — Security, Folder Sync, and Accessibility Improvements

Curated maintenance release of the native Android app improving folder synchronization, cloud sync security, store policy compliance, and accessible UI polish.

- **Single-file Folder Sync**: Each device now maintains a single `studyhabit_device_<id>.json` snapshot updated in place instead of creating a new file per sync, cleaning up older per-change snapshots created by the same device and reducing redundant background/PDF-page sync triggers.
- **Privacy & Cloud Sync Security**: Kept `blocker.*` (including installed app lists) strictly local and off remote/folder sync payloads, added synchronous token persistence and safer refresh resilience across transient errors, and hardened backend email normalization, atomic refresh rotation, validation bounds, and per-user sync locking.
- **App Blocker Disclosure & Android 10–16 Fallback**: Added an explicit in-app Prominent Disclosure & Consent dialog before opening Accessibility, Usage Access, or Display Over Other Apps settings, plus Usage Access + Display Over Other Apps blocking support for active study sessions.
- **UI & Accessibility Polish**: Fixed Achievements category tabs scrolling across all 7 categories, stacked Home overview cards cleanly at large font scales, improved Pomodoro overtime contrast, added inline `http://` warnings and friendly folder names in Cloud Sync settings, and surfaced explicit feedback when erasing cloud data.
- **Signed Artifacts**: Signed APK and AAB downloads preserve the existing StudyHabit signing identity and include verified package metadata and SHA-256 checksums.

Download the APK to install. The AAB is prepared for future store distribution.
