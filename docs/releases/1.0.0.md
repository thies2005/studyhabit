# StudyHabit 1.0.0 — Study sessions and focus

First curated stable release of the native Android app under the new 1.0.0 release series.

- Track study sessions with a Pomodoro timer and organize projects, subjects, and learning sources.
- Review study statistics, XP, streaks, and achievements.
- Use optional self-hosted synchronization and folder backup/restore, including folder synchronization fixes.
- Signed APK and AAB downloads include verified package metadata and SHA-256 checksums.

The displayed version restarts at 1.0.0; the Android version code increases. The existing StudyHabit signing key is preserved, so current signed installations can update. Uncommitted local development changes are not included.

Download the APK to install. The AAB is for future store distribution. Optional accessibility-based study blockers require explicitly enabling their Android permissions.
